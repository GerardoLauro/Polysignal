# Dati Polysignal

`examples/` contiene esclusivamente piccoli campioni originali e il dizionario dati. Il dataset completo, i dati grezzi e gli output della pipeline restano fuori da GitHub e sono ignorati da Git.

I campioni non consentono di ricostruire la dashboard completa. Se i dati privati sono disponibili, seguire le [istruzioni di configurazione](../docs/RUN_APP.md) e il manifesto storico `docs/BUNDLE_DATA.json`. Nessun archivio completo è incluso o richiesto per verificare i sorgenti.
